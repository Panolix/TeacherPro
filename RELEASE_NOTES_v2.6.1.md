# TeacherPro v2.6.1

A quick follow-up to v2.6.0. Everything from the big v2.6.0 release — bundled
fonts, the new right-click menus, clipboard support, shortcuts and the
printing fixes — is included here unchanged; this release only corrects one
visual detail in the editor's context menu.

## Fixed

- **"Select All Text" menu alignment** — the entry in the editor's
  right-click menu was the only row without a leading icon, which made it
  look shifted toward the middle of the menu. It now carries a matching
  icon and aligns flush-left with every other row.

Full feature list from v2.6.0 (bundled fonts, Word-style context menus with
cut/copy/paste, editor additions and Windows print fixes): see
`RELEASE_NOTES_v2.6.0.md`.

## For updaters

Your vault, lesson plans, mindmaps, materials and settings are untouched.
