# TeacherPro v2.10.1

Documentation update. No application code changed in this release.

## Changed

- README refreshed for 2.10.x: corrected the English settings label to
  **Settings → AI Features**, updated the model range (up to 31B, plus a
  35B-A3B mixture-of-experts model), and documented the hardware-based model
  recommendation and on-demand benchmark.
- Removed internal planning-document links from the README and fixed the
  platform and CI badges.

## Downloads

- **macOS**: `.dmg` (universal)
- **Windows**: `.msi` or `.exe` installer
- **Linux**: `.deb`, `.rpm` or `.AppImage`

> Release builds are unsigned. On macOS, right-click the app and choose **Open**
> the first time you launch it; on Windows, SmartScreen may ask you to confirm.
